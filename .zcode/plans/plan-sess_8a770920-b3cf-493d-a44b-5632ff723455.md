# Two-Stage Kit Check Redesign (rev 2)

## New flow

1. **Brief** (screen-space card, updated text): explains both stages — first sweep the bench and select everything that belongs in the LV rescue kit, then identify each item you selected.
2. **Stage 1 — Selection** (in-world, mouse captured): crosshair-click any bench item to toggle it in/out of the selection. Pool = all 16 manifest items **plus a new AED distractor** bound to the `AED Defibrilator Cabinet` mesh (per the user it sits on the bench with the tools; the name is just a Blender naming convention). Selected items get the existing `Interactable` outline highlight (same `material_overlay` mechanism as hover, distinct tint — green vs the yellow hover — so selected ≠ hovered). A non-blocking HUD chip shows "N selected — [Enter] to confirm"; `ui_accept` confirms stage 1.
3. **Stage 2 — Identification, diegetic panel**: for each item the student selected (manifest order), a **world-space panel** modeled on `cpr_panel_3d.gd` — SubViewport rendered onto a billboarded quad — floats above the currently-highlighted item, listing the name choices. Mouse stays captured; the student aims the crosshair at a row and presses `interact` to choose (row pick via ray-plane intersection, the same technique the casualty menu card used; aimed row highlights in the panel render). Choices = the item's true title + 3 titles drawn from the other manifest items (no reject option — they already claimed it's kit gear). Answering advances to the next item immediately.
4. **Closing** screen → "Begin simulation" → `SimState.begin_exercise()` as today.

Edge cases: confirming with nothing selected grades stage 1 failed and goes straight to closing. DevMenu warps still work — stage state tears down on `simulation_started`.

## Grading (silent, surfaced only in the debrief)

- **Stage 1 → new procedure step `kit_selected`** (`lvr_cpr_procedure.tres`: category `preparation`, no `requires`, weight 6, non-critical). Pass iff selected set == in-kit set. Per-item transcript logs ("Selected X" / "Wrongly selected X" / "Missed X" with each item's `rationale` in the detail) plus a summary line.
- **Stage 2 → existing step `kit_identified`** (weight 8): pass iff misidentifications ≤ `manifest.allowed_errors` (0), graded only over selected items, same logging style as today.
